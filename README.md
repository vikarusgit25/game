# 🐉 Flappy Dragon

**Flappy Dragon** — это динамичная 2D-аркада в жанре «бесконечный полёт», разработанная на игровом движке Godot Engine 4. Игрок управляет драконом, который должен пролетать между генерируемыми трубами, не задевая их и не падая на землю.

## 🎮 Геймплей

Управление драконом осуществляется нажатием клавиши **Пробел**. Каждое нажатие придаёт дракону импульс вверх. За успешный пролёт между трубами начисляется 1 очко. Игра продолжается до первого столкновения с трубой или землёй

## 🕹️ Управление

| Действие | Способ |
|----------|--------|
| Прыжок | Пробел|
| Пауза | Кнопка паузы на экране или Esc |
| Продолжить | Кнопка «ПРОДОЛЖИТЬ» |
| Вкл/Выкл звук | Кнопка динамика |
| Перезапуск | Кнопка «ИГРАТЬ» в окне Game Over |
| Меню | Кнопка «menu» в окне паузы |

## 🛠️ Технологии

- **Движок:** Godot Engine 4.2+
- **Язык:** GDScript
- **Размер окна:** 288x512 пикселей

## 🚀 Запуск проекта

1. Установите Godot Engine 4.2 или выше
2. Скачайте репозиторий
3. Откройте файл `project.godot`
4. Нажмите F5 или кнопку «Запустить проект»

## 📝 Системные требования

- ОС: Windows 10/11, Linux, macOS
- Процессор: 1.5 ГГц
- ОЗУ: 512 МБ
- Видеокарта: с поддержкой OpenGL 3.0
